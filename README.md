# Jamie's Robotics Notebook

A structured, long‑term notebook documenting my journey from beginner to fully capable robotics engineer.

This repository tracks my progress through a broad set of topics:

* **Modern Robotics** (Coursera) – kinematics, Jacobians, trajectories, and other mathematical foundations for robot manipulators.
* **IBM AI Engineering** (Coursera) – neural networks, computer vision, model deployment and optimisation.
* **ROS 2** from the ground up – nodes, topics, services, actions, TF2, URDF, RViz and ros2_control.
* **Simulation work** using CoppeliaSim to build digital twins and test control strategies before running on hardware.
* **Physical hardware** bring‑up for a Yahboom 6‑DOF Raspberry Pi 5 robot arm, using only custom code (no vendor software).
* **CAD and 3D printing** – designing and fabricating custom gripper fingers, mounts, base upgrades and other fixtures.
* **AI‑based perception and grasping** – training and deploying computer vision models on the robot for object detection and sorting.
* **Advanced topics** such as MoveIt 2 integration, reinforcement learning and motion optimisation.
* **Portfolio and job search** materials to support my career transition into robotics engineering.

The repository is organised in phases. Each phase corresponds to a stage in the roadmap and includes its own notes, tasks and experiments:

| Folder | Purpose |
| --- | --- |
| `00-roadmap` | High‑level roadmap describing what I plan to learn and build in each phase. |
| `01-foundations` | Early course notes (Modern Robotics, IBM AI Engineering) and fundamental tooling (ROS 2 basics, CoppeliaSim basics, CAD basics). |
| `02-skill-building` | Intermediate ROS 2 work, simulation projects, first perception models and CAD practice. |
| `03-robot-arrival` | Bringing up the physical robot arm with a custom software stack (no vendor code) and creating a digital twin. |
| `04-ai-perception` | Building computer vision nodes, integrating AI inference on the Pi 5 and implementing basic grasping logic. |
| `05-advanced` | MoveIt 2 integration, advanced perception or reinforcement learning projects, and major hardware upgrades. |
| `06-portfolio` | Videos, demos, separate repositories, CV drafts and job application tracking. |

The notes in this repository are written in Markdown. Use them as a living document – update checklists, jot down ideas, paste code snippets, sketch diagrams and record your observations. Each phase also contains a `notes.md` file for unstructured comments.
